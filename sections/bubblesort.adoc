== Bubblesort

[source,python]
----
for i in range(len(a) - 1):
    for j in range(len(a) - 1 - i):
        if a[j] > a[j + 1]:
            a[j], a[j + 1] = a[j + 1], a[j]
----

[.fragment]
Prendi due elementi vicini. Se sono nel ordine sbagliato, scambiali.

== Ma quanto costa?

Ogni passaggio confronta *tutte le coppie* adiacenti.

[.fragment]
Al passaggio *i* mancano ancora *n - i* elementi da sistemare.

[.fragment]
* (n-1) + (n-2) + … + 1 confronti

[.fragment.big]
≈ n² / 2 confronti

[.fragment.big]
O(n²)
