== Sleep Sort

E se fosse il tempo a ordinare?


[.fragment]
[source,js]
----
function sleepSort(arr) {
  arr.forEach(n => {
    setTimeout(() => {
      console.log(n);
    }, n * 100);
  });
}

sleepSort([4, 2, 7, 1, 3]);
----

[.fragment]
I numeri *si svegliano* nell'ordine corretto


[.white_bg]
== Una sveglia costosa

[.fragment]
`setTimeout` viene gestito dalla runtime del browser, ipotizziamo crei una coda con priorità.

[.fragment.big]
O(n log n + max(input))

[.fragment]
Abbiamo trasformato un problema algoritmico in un problema di scheduling
