== Slow Sort

[.column]
[source,python]
----
def slow_sort(A, i, j):
    if i >= j:                       # <1>
        return

    m = (i + j) // 2                 # <2>

    slow_sort(A, i, m)
    slow_sort(A, m+1, j)

    if A[m] > A[j]:                  # <3>
        A[m], A[j] = A[j], A[m]

    slow_sort(A, i, j-1)             # <4>
----

[.column]
<1> Caso base: zero o un elemento sono già ordinati.
<2> Divide la porzione in due metà.
<3> Porta il massimo in fondo alla porzione.
<4> Ripete l'ordinamento escludendo l'ultimo elemento.
