= Sort.happens
:author: Gabriele Grillo

Slides for the talk *"Sort.happens: Quando Bubble Sort sembra una buona idea"*, presented at DevFest Catania 2026.

Live deck: https://sort-happens.grimstack.xyz

The deck is written in AsciiDoc and rendered to HTML with https://asciidoctor.org[Asciidoctor] and https://revealjs.com[reveal.js]. Slide content is in Italian; this README and the tooling are in English.

== Requirements

* Node.js 24 (see `.nvmrc`, `nvm use` picks it up)
* npm
* Network access for builds: https://kroki.io[Kroki] diagrams (`[graphviz...]` blocks) are fetched while compiling

== Getting started

[source,bash]
----
npm ci                # install dependencies
npm run dev           # live-reload server on http://127.0.0.1:8123/presentation.html
PORT=9000 npm run dev # use a different port
----

`npm run dev` is the normal way to work: it rebuilds the deck whenever an `.adoc` file, the CSS, `docinfo-footer.html` or a plugin changes, and reloads the browser. The live-reload client is only injected into the HTTP response, it is never written to `presentation.html`.

Live reload only exists with the dev server: opening `presentation.html` from `file://` gives you a static page.

== Building

[source,bash]
----
npm run build
----

The build runs `scripts/sync-reveal.js` first (`prebuild`), which copies reveal.js from `node_modules` into `assets/js/reveal.js/` and extracts the theme fonts, then compiles `presentation.adoc` into `presentation.html`.

`assets/js/reveal.js/` and `assets/fonts/reveal/` are generated: do not edit them by hand and do not commit them. Custom plugins go in `assets/js/reveal.js-plugins/`, custom styles in `assets/css/reveal-override.css`.

== PDF export

Open `presentation.html?print-pdf` in a browser and print to PDF. The print stylesheet lives in `assets/css/reveal-override.css`. See the https://revealjs.com/pdf-export/[reveal.js PDF export documentation] for details.

== Deployment

* Pushes to `main` build the deck and publish it to GitHub Pages (`.github/workflows/static.yml`).
* Tags matching `v*` build the deck and attach a zipped `dist/` to a GitHub release (`.github/workflows/release.yml`).

== Repository layout

[source]
----
presentation.adoc               # root document: attributes and include order
sections/*.adoc                 # one file per topic, concatenated via includes
assets/css/reveal-override.css  # custom styles and slide classes
assets/images|video|fonts       # media
assets/js/reveal.js-plugins     # reveal.js plugins kept in the repo
docinfo-footer.html             # footer and support scripts (video, print, UI)
scripts/dev.js                  # dev server + file watcher
scripts/sync-reveal.js          # copies reveal.js from node_modules before the build
----

Slide order comes from the `include`s: `presentation.adoc` includes `sections/intro.adoc` and `sections/sort-happens.adoc`, and the latter includes the remaining sections at its end. To add a section, create `sections/name.adoc` and add the `include` at the right point of that chain.

== Writing slides

A slide is a level-2 title (`==`): one concept, short text, short lists. Section openers use `[.cover]` with a background image, regular text slides start with `[.white_bg]`, media live in `assets/`.

Authoring conventions, mobile and speaker-view constraints, and the checks to run before committing are in link:AGENTS.md[AGENTS.md].
